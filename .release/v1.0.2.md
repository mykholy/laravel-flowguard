# Laravel FlowGuard v1.0.2

This stable release updates documentation and package discovery metadata.

- Improve the README with status badges, practical failure scenarios, supported
  version tables, documentation navigation and server-derived merchant context.
- Update Composer discovery metadata for idempotency, webhook inbox,
  transactional outbox, reconciliation and fault tolerance.
- Replace stale blocked-publication wording with verified v1.0.1 release,
  exact-source workflow, Packagist and fresh public installation evidence.

```bash
composer require mykholy/laravel-flowguard:^1.0
php artisan migrate
php artisan flowguard:doctor
```

Runtime code, API signatures, dependencies and schema are unchanged. No data
migration or fingerprint rewrite is required. Preserve existing operation,
inbox, outbox and reconciliation identities; populated rollback is rejected.

Publication requires compatibility, clean archive installation, demo-host and
native-restore checks on the exact release source, followed by immutable
archive/checksum publication, Packagist indexing and a fresh public installation.
Existing release tags and artifacts remain unchanged.

The stable library contract and integration boundaries continue to apply.
Hosts own tenant authentication, verified webhook acceptance, provider
idempotency, timeouts, approvals, downstream deduplication and retention.
Delivery is at least once. Independent human security/adopter review and
representative production acceptance remain open.
